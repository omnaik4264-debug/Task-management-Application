# TaskFlow — Task Management Application

## Live Demo

https://omnaik4264-debug.github.io/Task-management-Application/

## Features
- User registration and login (browser localStorage demo)
- Create, read, update and delete tasks
- Task status and priority
- Due dates
- Search and filtering
- Dashboard statistics
- Responsive desktop/mobile design
- GitHub Pages compatible

## Note
This GitHub Pages version is a client-side demonstration. Data is stored in the browser using localStorage, so each browser/device has its own data.
